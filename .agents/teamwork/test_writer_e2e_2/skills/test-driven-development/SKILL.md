# Test-Driven Development (Local Snapshot)

## Core Methodology
- Write behavior-focused tests covering:
  1. Happy path (primary behavior)
  2. Edge cases and boundary conditions
  3. Failure and negative paths
  4. Integration and cross-component contracts
- Derived expected output from authoritative requirements, specifications, and reference behavior.
- Ensure test independence, repeatability, and clarity.
