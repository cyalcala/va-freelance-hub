source cohort. Increase their prospecting, validation, ATS resolution and feasible
polling attention until healthy steady state. Retain the worldwide universe,

remote opportunities first published per complete Manila day, with 150/day as

and the existing 28-day sustained-floor contract. Registry entries, observations,

## PH hiring priors and sparse allocation

| Conceptual prior | Evidence required | Scheduling interpretation |
| --- | --- | --- |
| PH_NATIVE | Verified platform/employer purpose primarily connecting Filipino workers | Highest PH attention prior |
| PH_TARGETED | Current first-party recruitment explicitly targets Philippine workers | Very high prior |
| PH_RECURRING | Repeated attributed historical PH hiring observations | High prior |
| PH_OBSERVED | Some evidenced PH-accessible postings | Moderate prior |
| GLOBAL_REMOTE | Evidenced global remote postings | Assess Philippines inclusion per posting |
| UNKNOWN | Missing/ambiguous evidence | No favorable eligibility assumption |

These are conceptual scheduling features, not writable lifecycle or eligibility
enums. Record evidence time, expiry, sample, uncertainty and version. Submitted
tier is separate from observed PH prior. A staffing agency's hiring history does
not make every job PH eligible. A source prior never overrides job geoGate.

Use the conceptual value function:

```text
Priority_i = PH_i * Freshness_i * MarginalYield_i
             * ChangeProbability_i * Reliability_i / Cost_i
Yield_i = NetNewQualifiedPHJobs_i / FetchCost_i
MarginalYield_i = JobsUniqueToSource_i / QualifiedJobsObserved_i
```

Measure inputs from lawful Turso history and compatible observation windows.
Cost includes requests, bytes, CPU, AI, latency and material orchestration/storage
overhead. Define comparable units, calibration and denominators. Zero/unknown
denominators are UNKNOWN, not infinite priority or measured zero yield. Report
qualification yield separately from realized fresh first-publication yield;
attribute overlapping canonical jobs once while retaining source sightings.

Apply action-specific feasibility before ranking: permission, current lease,
opt-out, robots, host limits, retry cooldown, source health and budgets. Hard
constraints cannot be traded for yield. Preserve deterministic family-stratified
control, independent permitted audit and nonzero cold-tail revisits. Use empirical
baselines, bounded P2 exploration and existing SSAE-00..15 evaluation; do not copy
DeepSeek constants or deploy unvalidated selector changes from a priority label.

```text
cheap recognition -> shared versioned memory -> sparse candidate selection
-> capability routing -> bounded paced fetch -> material delta
-> deterministic qualification -> publication gates -> observed economics
```

FULL obtains/processes new material evidence; REINDEX updates ranking/economics
from sufficient retained evidence; REUSE skips repeated deep work only while
material hashes, dependencies, expiry and durable decisions remain valid;
BOUNDED_REPLAY reevaluates the affected retained cohort after a rule change.
Withdrawals, opt-outs, safety or policy changes invalidate reuse. Do not refetch,
reparse, recompute immutable identity, reprobe a known family or rerun AI on an
unchanged compatible listing. Use deterministic rules before AI.

| DORMANT | Longer interval plus permitted recovery probes | Owned hold, cooldown or recovery trigger |

These classes are proposals, not current schedules or accepted parameter changes.
Use existing GCP scheduling/orchestration/Cloud Run/observability where evidenced;
recover the actual split with Worker and Actions before changing allocation.

cadence and shared-host pacing across runners. Record cooldown and recovery reasons.

The approximately 15-minute website freshness ambition is not a proven SLA.
An hourly publisher alone can impose more than 15 minutes of publication latency.

do not assert that faster upstream polling fixes publisher latency or silently
create a new clock to reconcile the two targets.

research, universe/source memory, observations and qualification reservoir. GCP
