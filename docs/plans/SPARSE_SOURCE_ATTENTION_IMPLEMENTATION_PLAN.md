# Sparse Source Attention Implementation Plan

**Date:** 2026-10-03. **Status:** PROPOSED supporting work register.
**Strategy:** [Sparse Source Attention](../strategies/SPARSE_SOURCE_ATTENTION_STRATEGY.md).
**Execution authority:** [Source Perpetuity implementation plan](SOURCE_PERPETUITY_IMPLEMENTATION_PLAN.md).

## Dispatch and evidence rules

SSAE-00 through SSAE-15 are bounded supporting cards, not a second executable
source queue. All start PROPOSED; no implementation, deployment, observation or
acceptance is implied. Map a selected card to the current source unit and
relevant [MATH cards](MATHEMATICAL_IMPROVEMENT_PLAN.md) before execution. Retain
the 13 challenges; no accepted MATH-14 is created. Current publication-control
incidents and the source plan's dependency gates take priority over rollout.

Recover AGENTS, any present manifest, accepted authority/parameters, CURRENT,
savepoint, canonical master/execution prompts and the current source contract.
Fetch, preserve dirty/foreign work and restate full HEAD/origin/main SHAs. Code
anchors in the strategy are dated code evidence; remeasure runtime and data.
Do not carry the attachment's source/job counts into a new experiment baseline.

Every dispatched unit needs a falsifiable hypothesis, immutable input/window,
defined effect and noninferiority margins, bounded budgets/blast radius, owner,
verification, failure and rollback contract. Respect the existing parameter
lifecycle; unset experimental values are proposals. Network probes, DB writes,
deployment and publication each require their actual existing authority. A
read-only shadow has no extra probes. An audit is a distinct permitted workload.

Common exit evidence records code, deployment, observation and acceptance
separately. Missing outcomes are unknown/censored. Failed evidence can yield
REVISE, retain-baseline or dormant disposition; it cannot be converted into KEEP
by elapsed time. Stop affected unsafe work and continue independent bounded work.

SSAE-01/04/05 may finish LIMITED with an explicit label/telemetry coverage gap,
owner and measurement trigger. That disposition can dispatch a separately
permitted, precontracted SSAE-06 audit or instrumentation slice to obtain the
missing evidence; successful ranker benefit is not a prerequisite for collecting
labels. LIMITED supplies no rollout acceptance or authority to probe. Rebuild
the dataset and repeat the affected evaluation after measurement matures.

## SSAE supporting cards

### SSAE-00 — Recover reality and profile end-to-end costs

- **Dependencies/scope:** current parent source unit; MATH-13 and relevant existing MATH cards; read-only code and available operational evidence.
- **Deliver:** actual selection/fetch/wait/parse/geo/AI/DB/publication boundary map, clocks, schedules, stage costs, missing telemetry and comparable workload definition.
- **Verify/exit:** reproducible profile with source-level failures, CPU vs network vs intentional pacing, cache/ledger overhead, queue boundaries and an Amdahl hypothesis; no invented current counts.
- **Failure/rollback:** unavailable telemetry yields an owned measurement gap; no runtime change to revert. Hypothesis can reject selection as the dominant bottleneck.

### SSAE-01 — Build an as-of-selection attention dataset

- **Dependencies/scope:** 00; MATH-01/05/09; existing lawful lake/run/publication evidence, read-only derivation.
- **Deliver:** versioned source-action contexts, actual resource costs, compatible mature marginal canonical fresh publication outcomes, intermediate discoveries/holds, censoring and attribution.
- **Verify/exit:** schema/query manifest, temporal/independent-label coverage, deduplication and leakage checks; unselected outcomes remain unknown. Insufficient labels yield LIMITED plus an owned gap and a bounded SSAE-06 measurement contract.
- **Failure/rollback:** inadequate reward/exposure history prevents benefit acceptance, but can motivate separately permitted audit/instrumentation; archive or rebuild derived artifacts without rewriting original evidence.

### SSAE-02 — Define compact source memory and dependency contract

- **Dependencies/scope:** 00/01; MATH-06/09/10; map existing storage before additions.
- **Deliver:** proposed typed fields, fact owner/replication direction, action feasibility, material digests, version dependencies, TTL/retention and exact replay coverage matrix.
- **Verify/exit:** state fixture cases for missing evidence, unknown dependencies, policy/opt-out expiry, concurrent versions and URL/content distinction; no unsupported enum writes.
- **Failure/rollback:** missing raw fields are a documented hold/FULL requirement; revert a proposed derivation/type without affecting source authority.

### SSAE-03 — Implement a pure read-only source ranker

- **Dependencies/scope:** 02; MATH-01/13; proposed additive ranker adjacent to `scripts/lake/reconcile-discovered-corpus.ts`, actual sampler unchanged.
- **Deliver:** frozen-input Top-K/candidate pool, simple empirical baseline, score/cost decomposition, exclusions and cold revisit reasons; no learned model required.
- **Verify/exit:** deterministic parity/reproducibility, resource/authority exclusion fixtures, bounded ranker cost and no network/production mutation side effects.
- **Failure/rollback:** discard or disable the advisory report; deterministic family-stride control remains available.

### SSAE-04 — Evaluate historical temporal holdouts

- **Dependencies/scope:** 01/03; MATH-01/05/13; offline/read-only, as-of features and matured labels.
- **Deliver:** compare deterministic stride and empirical baselines, plus a properly simulated random design where supported; cost/yield/calibration on explicit observed cohorts.
- **Verify/exit:** leakage-free temporal split, uncertainty, matched budgets, overlap/deduplication, missing outcomes and limitations; insufficient history yields LIMITED and an SSAE-06 measurement request, never unsupported benefit/recall acceptance.
- **Failure/rollback:** retain simpler baseline if benefit is absent; preserve negative report and remove unjustified model complexity.

### SSAE-05 — Run shadow decisions without extra probes

- **Dependencies/scope:** 04; existing permitted run evidence only; current selector controls real work.
- **Deliver:** advisory choices from the same frozen state, selected overlap, ranking latency, mode proposals, feasibility reasons and known/unknown outcome coverage.
- **Verify/exit:** representative cycle evidence proves no scheduling, source-policy, publication or hypothetical-candidate network effects; complete versioned receipts. Missing alternative outcomes yield LIMITED and may route to separately permitted SSAE-06 measurement.
- **Failure/rollback:** disable shadow hook/report if cost, correctness or isolation fails; hypothetical yield remains unknown until separately observed.

### SSAE-06 — Contract and evaluate a randomized permitted audit

- **Dependencies/scope:** 01 and available 04/05 findings, including LIMITED gaps; MATH-03/05/08. Separately contract lawful instrumentation or an eligible audit population, probe authority and budgets before live work; no successful ranker-benefit prerequisite.
- **Deliver:** instrumentation/coverage repair or sample unit/strata/seed, actual inclusion probabilities, host/duplicate clustering, horizon, missingness and analysis contract; deterministic stride is a separate reproducible control.
- **Verify/exit:** mature versioned measurement receipts repair specified gaps and feed 01/04/05. Audit inference additionally requires permitted probes, support/positivity and sample-power evidence; HT/propensity or recall claims need valid design. LIMITED evidence cannot accept rollout.
- **Failure/rollback:** stop the audit workload and retain lawful receipts; weak sample coverage blocks graduation, not source authority checks.

### SSAE-07 — Implement exclusive processing modes and cache validity

- **Dependencies/scope:** 02 and caller audit from 00; MATH-06/10; bounded integration with existing conditional-fetch paths.
- **Deliver:** FULL/REINDEX/REUSE/BOUNDED_REPLAY per entity/action/epoch, separate disposition, authoritative invalidation, conservative unknown dependencies and versioned checkpoints.
- **Verify/exit:** TTL/policy/lease/opt-out/schema/model invalidation, missing body/304, concurrent changes and retry fixtures; 304 costs a request and does not renew source observations.
- **Failure/rollback:** restore accepted cache/selector version; hold unsafe reuse, honor current withdrawals and recover affected decisions through existing controls.

### SSAE-08 — Maintain an incremental hierarchical candidate pool

- **Dependencies/scope:** 02/03; MATH-01/03/13; use existing coherent family/host/provenance facts.
- **Deliver:** bounded summaries/pools, event-driven updates, periodic bounded rebuild/audit, cold revisit triggers, hysteresis and memory limits.
- **Verify/exit:** skew/cold-start/stale-summary/load fixtures, audit coverage and rows-read/update costs; demonstrate no full O(N) rescore/heartbeat each epoch disguised as sparsity.
- **Failure/rollback:** restore control enumeration in a bounded mode; fence stale pools and retain identity/evidence rather than deleting cold sources.

### SSAE-09 — Add field-sensitive job delta and exact bounded replay

- **Dependencies/scope:** 02/07; MATH-05/06/09/10; existing ingest/replay paths, preserving sightings and original clocks.
- **Deliver:** identity-independent material digests, version dependency closure, complete-snapshot proof, exact bounded reconstruction and idempotent supersession. Restrictive replay covers qualified/synced/public records and propagates exclusions/withdrawals through governed serving-store/cache paths.
- **Verify/exit:** same URL with changed geography/remote/date/link/safety, unchanged IDs with changed fields, partial snapshot, unknown dependencies, expired evidence, cursor/restart/concurrency fixtures and public withdrawal propagation; no affected positive-state cohort omitted.
- **Failure/rollback:** hold affected jobs, stop absence-derived writes, restore accepted cache logic and preserve governed withdrawal propagation; no new first-publication clocks or withdrawn-data restoration.

### SSAE-10 — Build a deterministic constrained allocator

- **Dependencies/scope:** 03–09 sufficient evidence plus MATH-02 capacity and MATH-06 gateway controls; remain advisory until 14.
- **Deliver:** action-specific hard feasibility, marginal deduplicated reward, multi-resource reservations, accepted concentration/cadence, global host domains and dynamic bounded K.
- **Verify/exit:** deterministic fallback, over-budget/missing-telemetry/retry/cooldown/host-overlap/queue-shock fixtures, ledger reconciliation and matched-control cost benefit.
- **Failure/rollback:** restore the last accepted selector and fence outstanding reservations; a high score never permits a forbidden action.

### SSAE-11 — Optionally test uncertainty-aware exploration

- **Dependencies/scope:** 06/10; MATH-01/03/08; only if cold-tail evidence justifies complexity.
- **Deliver:** simple audit/fair revisit baseline before optional Thompson/count-model/dual-price experiments; bounded coefficients, steps, exploration spend and independent audit stream.
- **Verify/exit:** calibrated uncertainty, temporal validation, cold-start/saturation/oscillation and cost tests; actual propensities or explicit limits on off-policy inference.
- **Failure/rollback:** remove adaptive layer and restore deterministic allocator; an underpowered experiment is unresolved, not accepted improvement.

### SSAE-12 — Optionally add globally paced host-sharded GCP work

- **Dependencies/scope:** 00/07/10 and accepted operational plane; MATH-02/04/08/13; only when wait-time profiling proves value.
- **Deliver:** bounded independent-host lanes with shared provider budgets across shards, schedulers, ATS tenants and retries; existing deployment path, no new service by default.
- **Verify/exit:** global lease/rate reservations, duplicate-clock fencing, 429/backoff/crash/retry/queue drills, permitted cadence and end-to-end cost/latency comparison.
- **Failure/rollback:** fence/drain shards, restore accepted execution concurrency/pacing; never rely on a separate local delay in each worker for a global limit.

### SSAE-13 — Measure and bound AI value of information

- **Dependencies/scope:** 01/02/09 and MATH-05/06/11; existing authorized deterministic and AI/Jev paths.
- **Deliver:** ambiguity-class routing, independent adjudication, total inference/delay/error/retry cost, abstentions and evidence/model/prompt dependency cache.
- **Verify/exit:** compare AI against deterministic/fallback decisions on mature matched cases; no repeated inference of known facts or model-generated permission.
- **Failure/rollback:** restore existing deterministic/deferred behavior; reduce optional AI when measured value fails, within accepted decision-class controls.

### SSAE-14 — Run a bounded scheduling canary

- **Dependencies/scope:** accepted 00–10 evidence, explicit optional-card dispositions, current source/gateway controls and a predeclared live experiment contract.
- **Deliver:** capped scheduling share for currently permitted actions, reproducible control and separately budgeted audit; all publication paths unchanged.
- **Verify/exit:** exact-SHA deploy/run evidence, powered representative mature reward window, benefit/noninferiority/coverage margins, host/queue/quality limits and rollback drill.
- **Failure/rollback:** immediately restore accepted selector/cache version on declared regressions; propagate withdrawal, fence in-flight work and preserve lawful negative evidence.

### SSAE-15 — Decide graduation and prove independent recovery

- **Dependencies/scope:** 14 mature evidence; Source Perpetuity acceptance/release gates; no automatic system-wide cutover.
- **Deliver:** KEEP/REVISE/retain-baseline decision with complete costs, mature canonical fresh rewards, uncertainty, independent quality/audit coverage and source-scoped rollback/resume drill.
- **Verify/exit:** no unresolved hard-control violations, meaningful accepted benefit or justified baseline retention, monitoring/reopen triggers and executable evidence links.
- **Failure/rollback:** immature or missing evidence keeps rollout unaccepted; accepted graduation covers this exact intervention/version and does not certify 13/13, supply floor or perpetuity.
