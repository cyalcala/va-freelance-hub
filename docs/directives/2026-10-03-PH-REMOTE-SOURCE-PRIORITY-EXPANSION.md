Introduce or derive a **PH hiring prior** for scheduling and source ranking.

```text
PH_NATIVE
PH_TARGETED
PH_RECURRING
PH_OBSERVED
GLOBAL_REMOTE
UNKNOWN
```

Interpretation:

### PH_NATIVE

The platform or employer exists specifically or primarily to connect Filipino workers with remote employers.

Highest source-attention prior.

### PH_TARGETED

Current first-party evidence explicitly recruits Philippine workers.

Very high source-attention prior.

### PH_RECURRING

Repeated historical PH hiring observations exist.

High source-attention prior.

### PH_OBSERVED

Some PH-accessible jobs have been observed.

Moderate prior.

### GLOBAL_REMOTE

Global remote jobs exist but Philippines inclusion must be evaluated individually.

### UNKNOWN

No favorable assumption.

IMPORTANT:

The source prior changes **where the crawler spends attention**.

It must NEVER override the job-level geo gate.


does NOT imply:

```text

```

# 13. SOURCE ATTENTION SCORE

Within the existing sparse architecture, bias candidate selection using a value function equivalent to:

\[
Priority_i =
PH_i
\times Freshness_i
\times MarginalYield_i
\times ChangeProbability_i
\times Reliability_i
\div Cost_i
\]

Where:

```text
PH_i
= historical probability of PH-accessible jobs

Freshness_i
= importance of rapid detection

MarginalYield_i
= unique qualified jobs not already found elsewhere

ChangeProbability_i
= likelihood the source changed since last observation

Reliability_i
= endpoint and parser health

Cost_i
= requests + bytes + CPU + AI + latency
```

Do not copy arbitrary constants from DeepSeek architecture.

Measure these empirically.

Use source history in Turso.
