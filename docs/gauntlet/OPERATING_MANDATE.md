# 17 — INTERRUPTION / CREDIT-EXHAUSTION PROTOCOL

The project must remain recoverable even when an executor stops unexpectedly.

Before starting a substantial unit:

```text
SYNC REPOSITORY
↓
READ EXECUTION_STATE
↓
VERIFY LAST CHECKPOINT
↓
CREATE / SELECT SAFE BRANCH OR WORKTREE
↓
RECORD UNIT ID
```

If a model detects that it cannot safely finish the current unit because of:

* context exhaustion
* token exhaustion
* credit exhaustion
* provider failure
* unexpected session termination risk
* missing dependency
* unresolved blocker

it must stop at the safest available boundary and preserve state.

The handoff must record:

```text
UNIT ID

CURRENT STATUS

WHAT WAS COMPLETED

WHAT REMAINS

FILES CHANGED

COMMANDS / TESTS RUN

TEST RESULTS

UNVERIFIED ASSUMPTIONS

KNOWN FAILURES

CURRENT BRANCH / WORKTREE

LAST SAFE COMMIT

NEXT EXACT ACTION

RECOMMENDED EXECUTOR
```

If useful partial code exists:

* preserve it on the isolated branch
* mark it clearly as WIP
* commit it only to the working branch if doing so improves recoverability
* push the branch to GitHub
* do not merge it into accepted/main state
* do not mark the Gauntlet unit complete

The state becomes:

```text
PAUSED
BLOCKED
or
ESCALATE
```

never falsely:

```text
KEEP
```

The next model must be able to resume from GitHub without needing the previous model's conversation.

# 89 — AUTONOMY MATURITY MODEL

Autonomy is earned progressively.

## LEVEL 0 — MANUAL

Human/model discovers and diagnoses everything manually.

## LEVEL 1 — OBSERVABLE

The system exposes trustworthy operational state.

## LEVEL 2 — SELF-DETECTING

The system identifies abnormal conditions automatically.

## LEVEL 3 — SELF-EVIDENCING

The system automatically collects useful diagnostic evidence.

## LEVEL 4 — SELF-NARROWING

The system identifies likely fault domains and relevant symbols/tests/incidents.

## LEVEL 5 — GUARDED SELF-RECOVERY

Known safe recoveries can run automatically under explicit boundaries.

## LEVEL 6 — SELF-VERIFYING

Recovery is automatically verified rather than assumed.

## LEVEL 7 — AGENT-OPERABLE

An engineering model receives a bounded diagnostic package and can work from minimal context.

Do not skip levels merely to claim autonomy.
